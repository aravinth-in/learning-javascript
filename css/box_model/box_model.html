CSS Box Model

Example 1: Default `content-box` behavior

I am a box with `content-box` (default). My content area is 150x100px. Padding and border add to my total size.

This box has `width: 150px`, `height: 100px`, `padding: 20px`, and `border: 5px solid`. Since `box-sizing: content-box` (default), its **actual rendered width** will be 150px (content) + 20px (left padding) + 20px (right padding) + 5px (left border) + 5px (right border) = **200px**. Its **actual rendered height** will be 100px (content) + 20px (top padding) + 20px (bottom padding) + 5px (top border) + 5px (bottom border) = **150px**.

Example 2: `border-box` behavior

I am a box with `border-box`. My total visible size (including padding & border) is 150x100px.

This box also has `width: 150px`, `height: 100px`, `padding: 20px`, and `border: 5px solid`. However, with `box-sizing: border-box`, its **actual rendered width** will be exactly **150px** and its **actual rendered height** will be exactly **100px**. The content area shrinks to accommodate padding and border.

Example 3: Margin Collapse (Vertical)

Top box (margin-bottom: 30px)

Bottom box (margin-top: 40px)

When vertical margins of adjacent block-level elements touch, they collapse. The top box has `margin-bottom: 30px`. The bottom box has `margin-top: 40px`. Instead of 30px + 40px = 70px space, the space between them will be the **larger of the two margins**, which is **40px**.

Example 4: Padding and Margin Differences

This is content inside the inner element.

The `outer-container` has a background. The `inner-element` has padding and margin. Notice how **padding** (`20px` in `inner-element`) pushes the content away from its *own border* and takes on the `inner-element`'s background color. **Margin** (`30px` in `inner-element`) creates space *outside* its border, pushing it away from the `outer-container`'s boundary, and this space is transparent (shows the `outer-container`'s background).
