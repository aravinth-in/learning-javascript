Example 4.3: Responsive Image Gallery (`auto-fit` & `minmax`)

.container-gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 15px; }
(Columns adjust dynamically based on viewport width)
