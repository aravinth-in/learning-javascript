CSS Grid: Alignment & Justification

Example 3.1: `justify-items` (Item Horizontal Alignment)

Start
End
Center
Stretch

.grid-container { display: grid; grid-template-columns: repeat(4, 1fr); justify-items: start; }
.item-end { justify-self: end; }
.item-center { justify-self: center; }
.item-stretch { justify-self: stretch; }
