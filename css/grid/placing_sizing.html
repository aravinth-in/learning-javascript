CSS Grid: Placing & Sizing Items

Example 2.1: Placing Items by Line Numbers

Item A (Col 1-3)
Item B (Col 3-5, Row 1-3)
Item C (Col 1, Row 2)
Item D (Col 2, Row 3)

.container-place-lines { grid-template-columns: repeat(4, 1fr); grid-template-rows: repeat(3, 100px); }
.item-a { grid-column: 1 / 3; }
.item-b { grid-column: 3 / 5; grid-row: 1 / 3; }
.item-c { grid-column: 1; grid-row: 2; }
.item-d { grid-column: 2; grid-row: 3; }

Example 2.2: Spanning Items (`span`)

Span A (Col span 3)
Span B (Row span 2)
Span C
Span D

.container-span { grid-template-columns: repeat(4, 1fr); grid-template-rows: repeat(2, 120px); }
.item-span-a { grid-column: span 3; }
.item-span-b { grid-row: span 2; }

Example 2.3: `grid-area` (Shorthand for lines)

Area 1 (1/1/3/2)
Area 2 (1/2/2/4)
Area 3 (2/2/3/4)

.container-grid-area-lines { grid-template-columns: repeat(3, 1fr); grid-template-rows: repeat(2, 120px); }
.item-area-1 { grid-area: 1 / 1 / 3 / 2; }
.item-area-2 { grid-area: 1 / 2 / 2 / 4; }
.item-area-3 { grid-area: 2 / 2 / 3 / 4; }

Example 2.4: `grid-template-areas` (Naming and Visual Layout)

Header
Nav
Main Content
Sidebar
Footer

.container-named-areas {
grid-template-columns: 100px 1fr 200px;
grid-template-rows: 60px 1fr 80px;
grid-template-areas:
"head head head"
"nav main side"
"foot foot foot";
}
.header-item { grid-area: head; } /* etc. */
