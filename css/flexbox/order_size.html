Flexbox: Ordering & Sizing Items

Example 3.1: `order` Property

Item A (order: 2)
Item B (order: 0)
Item C (order: -1)
Item D (order: 1)

.item-order-2 { order: 2; }
.item-order-0 { order: 0; }
.item-order-minus1 { order: -1; }
.item-order-1 { order: 1; }

Example 3.2: `flex-grow` Property

Grow 0
Grow 1
Grow 2
Grow 1

.item-grow-0 { flex-grow: 0; }
.item-grow-1 { flex-grow: 1; }
.item-grow-2 { flex-grow: 2; }

Example 3.3: `flex-shrink` Property

Shrink 1 (Default)
Shrink 0 (Won't shrink)
Shrink 2 (Shrinks more)
Shrink 1

.item-shrink-1 { flex-shrink: 1; }
.item-shrink-0 { flex-shrink: 0; }
.item-shrink-2 { flex-shrink: 2; }

Example 3.4: `flex-basis` Property

Basis: auto
Basis: 100px
Basis: 20%

.item-basis-auto { flex-basis: auto; }
.item-basis-100px { flex-basis: 100px; }
.item-basis-20 { flex-basis: 20%; }

Example 3.5: `flex` Shorthand

flex: 1
flex: none
flex: 0 0 200px

.item-flex-1 { flex: 1; }
.item-flex-none { flex: none; }
.item-flex-00200 { flex: 0 0 200px; }

Example 3.6: `align-self` Property

Default
Align Start
Align End
Align Center
Default

.flex-container { align-items: stretch; /* or any default */ }
.item-align-self-start { align-self: flex-start; }
.item-align-self-end { align-self: flex-end; }
.item-align-self-center { align-self: center; }
